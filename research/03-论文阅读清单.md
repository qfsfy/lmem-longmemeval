# 论文阅读清单（按优先级）

> 调研日期：2026-09-21 ｜ P0 = 立项必读，P1 = 设计阶段精读，P2 = 拓展视野

## P0 — 立项必读（先读这 6 篇）

| 论文 | 出处 | 一句话核心 | 对本项目的意义 |
|---|---|---|---|
| **LongMemEval**: Benchmarking Chat Assistants on Long-Term Interactive Memory (arXiv:2410.10813) | ICLR 2025 | 500 题长程记忆基准 + 五大能力分解 | 目标基准，题型定义即需求文档 |
| **A Survey on the Memory Mechanism of LLM-based Agents** (arXiv:2404.13501) | Zhang et al. 2024 | 记忆的写入/管理/读取三环节系统综述 | 建立领域全景词汇表 |
| **Memory in the Age of AI Agents** (arXiv:2512.13564) | 2025 末最新综述 | 形式/功能/动态性的细粒度分类法 | 补充 2025 年新进展；配套 [GitHub 论文列表](https://github.com/nuster1128/LLM_Agent_Memory_Survey) |
| **MemGPT**: Towards LLMs as Operating Systems (arXiv:2310.08560) | 2023 | OS 式分层虚拟上下文，agent 自主换页记忆 | 分层记忆思想的源头，Letta 的前身 |
| **Mem0**: Building Production-Ready AI Agents with Scalable Long-Term Memory (arXiv:2504.19413) | 2025 | 抽取-更新两阶段记忆流水线（ADD/UPDATE/DELETE/NOOP） | 工业界最常用方案，复现首选 |
| **LOCOMO**: Evaluating Very Long-Term Conversational Memory of LLM Agents (arXiv:2402.17753) | ACL 2024 | 超长对话记忆基准 + 时间事件图 | 第二评测场，与 LongMemEval 交叉验证 |

## P1 — 架构设计阶段精读

| 论文 | 出处 | 一句话核心 |
|---|---|---|
| **Zep**: A Temporal Knowledge Graph Architecture for Agent Memory (arXiv:2501.13956) | 2025 | 双时间轴 KG + 边失效，直接对应"知识更新/时间推理"两类题型 |
| **A-MEM**: Agentic Memory for LLM Agents (arXiv:2502.12110) | 2025 | Zettelkasten 式记忆笔记，新记忆触发旧记忆演化 |
| **HippoRAG**: Neurobiologically Inspired Long-Term Memory for LLMs (arXiv:2405.14831) | NeurIPS 2024 | KG + Personalized PageRank 做多跳联想检索 |
| **From RAG to Memory (HippoRAG 2)** (arXiv:2502.14802) | ICML 2025 | 非参数持续学习：事实/语义/联想三类记忆任务全面超 RAG |
| **MemOS**: A Memory OS for AI System (arXiv:2507.03724) | 2025 | 记忆一等公民 + MemCube 抽象 + 显式 KV 缓存记忆 |
| **MemoryBank**: Enhancing LLMs with Long-Term Memory (arXiv:2305.10250) | 2023 | 艾宾浩斯遗忘曲线的记忆衰减机制（早期经典） |
| **Generative Agents** (arXiv:2304.03442) | UIST 2023 | 记忆流 + 相关性/时新性/重要性三因素检索打分 + 反射 |
| **RAPTOR** (arXiv:2401.18059) | 2024 | 递归树状摘要索引 |
| **GraphRAG**: From Local to Global (arXiv:2404.16130) | Microsoft 2024 | 社区层次摘要做全局问答 |
| **MemoRAG** (arXiv:2409.05591) | 2024 | 全局记忆模型草拟线索引导精检索 |

## P2 — 拓展视野

| 论文 | 出处 | 一句话核心 |
|---|---|---|
| **CoALA**: Cognitive Architectures for Language Agents (arXiv:2309.02427) | 2023 | 工作记忆/情景/语义/程序记忆的认知架构统一框架（写论文时做分类框架很好用） |
| **Titans**: Learning to Memorize at Test Time (arXiv:2501.00663) | Google 2025 | 模型内部长时记忆层（神经记忆），架构级路线 |
| **PerLTQA** (arXiv:2402.16288) | 2024 | 个人长时记忆的分类/检索/融合 |
| MemBench / MemoryAgentBench | 2025 | agent 记忆专项评测（按名检索最新版本） |
| LoCoMo-Plus | 2026 | 超越事实型的认知记忆评测（LOCOMO 衍生） |
| LongMemEval-V2 | 2026/05 官宣 | agentic-context memory 方向，保持关注 |

## 阅读顺序建议

```
第 1 周：LongMemEval → 综述两篇（建立全景） 
第 2 周：MemGPT → Mem0 → Zep（三大流派：分层上下文 / 抽取更新 / 时序KG）
第 3 周：A-MEM → HippoRAG 1/2 → MemoryBank（agentic 记忆与联想检索）
第 4 周：LOCOMO + 幻觉专题论文（见 04-幻觉抑制专题.md）
```

每篇按统一模板做笔记（建议放 `research/notes/` 下）：
**问题定义 / 架构图 / 记忆写入-管理-读取机制 / 评测与结果 / 可借鉴点 / 局限与批判**。
