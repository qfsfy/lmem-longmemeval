# 幻觉抑制专题

> 项目目标之二：减轻 AI 幻觉。本文件梳理成因、技术路线，以及与 LongMemEval 五类题型的机制映射。

## 1. 记忆系统视角下的幻觉成因

1. **参数化记忆过时/缺失**：模型内部知识陈旧或错误，又没有外部记忆兜底 → 编造；
2. **上下文噪声**：长历史检索进来的无关内容淹没了证据 → 张冠李戴；
3. **知识更新冲突**：用户改了偏好/事实（"我已搬到北京"），旧记忆未失效 → 新旧矛盾作答；
4. **过度自信作答**：证据不足时仍强行回答 → 这正是 LongMemEval 的 **Abstention** 题型要抓的失败模式。

## 2. 三条抑制路线

### 路线 A：接地（Grounding）——把答案锚定在记忆证据上
- 检索增强生成 + **强制引用（citation）**：答案必须附带证据会话/轮次 ID；
- 忠实度评估：**RAGAS**（arXiv:2309.15217）的 faithfulness 指标可纳入开发期自动回归测试；
- 代表实践：Zep/Graphiti 的边失效保证接地内容不陈旧。

### 路线 B：自检与验证（Self-verification）
- **SelfCheckGPT**（arXiv:2303.08896）：采样一致性检测幻觉句；
- **Chain-of-Verification (CoVe)**（arXiv:2309.11495）：生成答案 → 自动拟验证问题 → 逐条核查 → 修订；
- 成本较高，适合只在"高 stakes"回答或评测管道中使用。

### 路线 C：校准拒答（Calibrated Abstention）——对齐基准的 `_abs` 题型
- 检索置信度门控：证据相似度/覆盖率低于阈值 → 明确回答"不记得/不知道"；
- 生成端指令：允许并鼓励拒答（很多模型默认强答，需要显式 prompt + 微调）；
- 不确定性表达：token 级置信度、自洽性（self-consistency）方差作为拒答信号。

### 入门综述
- *A Survey on Hallucination in LLMs*（arXiv:2311.05232）——幻觉分类学（事实性 vs 忠实性）；
- *A Comprehensive Survey of Hallucination Mitigation Techniques*（arXiv:2401.01313）——32+ 种缓解技术总览。

## 3. 机制映射：五类题型 → 记忆系统设计

| LongMemEval 题型 | 失败模式 | 记忆系统机制 |
|---|---|---|
| 信息抽取（用户/助手/偏好） | 检索不准 | 混合检索（BM25 + 稠密 + rerank），会话级+轮级两级索引 |
| 多会话推理 | 单路检索漏证据 | 图结构联想（KG + PPR）或多次迭代检索 |
| 时间推理 | 忽略时间序 | 全链路时间戳元数据；bi-temporal；时序查询扩展与剪枝 |
| 知识更新 | 新旧记忆冲突 | 写入时 UPDATE/DELETE 旧条目（Mem0 式操作）；边失效（Graphiti 式）；记忆版本化 |
| **拒答** | 无证据硬答 | 置信度门控 + 拒答校准 + 引用缺失即拒答 |

> 设计含义：**"知识更新"与"拒答"两类题型就是幻觉问题的基准化表达**，架构设计时把"记忆生命周期管理"和"证据门控"作为一等公民，而不是事后补丁。

## 4. 开发期可落地的反幻觉检查清单

- [ ] 每个答案可回溯到至少一条记忆条目（引用 ID）；
- [ ] 记忆写入时有冲突检测（与既有记忆矛盾 → 触发更新/失效而非并存）；
- [ ] 检索 top-k 相似度低于阈值时走拒答分支；
- [ ] 回归测试集包含 `_abs` 类样本，监控"该拒未拒"与"不该拒误拒"两个方向的错误率；
- [ ] 用 RAGAS faithfulness 做自动化忠实度回归。
